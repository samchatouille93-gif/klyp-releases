# KLYP

Enregistreur de clips de jeu pour Windows : clippe tes meilleurs moments en un raccourci, monte-les dans le Studio, partage-les avec tes potes.

## Télécharger

👉 **[Télécharger KLYP pour Windows](https://github.com/samchatouille93-gif/klyp-releases/releases/latest/download/KLYP-Setup.exe)** (Windows 10 / 11, 64 bits)

KLYP se met à jour tout seul : quand une nouvelle version sort, elle s'installe à la prochaine fermeture de l'appli.

## « Windows a protégé votre PC » ?

KLYP n'est pas encore signé numériquement, donc Windows affiche un avertissement la première fois.
Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.
